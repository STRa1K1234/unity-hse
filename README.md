# Unity, семинары

Домашние задания с семинаров по разработке игр на Unity.
Каждая папка — самостоятельный проект Unity 6.6 (6000.6.5f1), открывать её целиком
через Unity Hub (Add → Add project from disk).

| Задание | Папка | Тема |
|---|---|---|
| lvl.01 | [`lvl01/`](lvl01/) | спавнер: размещение N объектов в настраиваемой области, вызов метода у всех |
| lvl.02 | [`lvl02/`](lvl02/) | вращения через иерархию: орбита, собственное вращение, движение и облёт камеры |

Подробности по каждому заданию — в README внутри папки.

Папка `Library/` в репозиторий не кладётся: она генерируется Unity при первом открытии
проекта, весит сотни мегабайт и к исходному коду отношения не имеет.
