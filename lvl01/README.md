# Семинар lvl.01 — спавнер

Домашнее задание: спавнер, который при запуске игры размещает N объектов из префаба
в настраиваемой области и вызывает у каждого метод `WriteLog(int i)`.

## Что сделано

- **на 6** — `Spawner` создаёт `Number` копий префаба с видимым мэшем (куб) при старте сцены.
- **на 8** — на префабе висит `SpawnedObject` с методом `void WriteLog(int i)`.
  Спавнер сначала размещает все объекты, запоминая их в `List<SpawnedObject>`,
  и только после этого проходит по списку и вызывает `WriteLog(i)` — в консоли
  появляется `Number` сообщений с разными `i`.
- **на 10** — область размещения задаётся полем `Area Size` в инспекторе спавнера,
  точки считаются через `Random.Range` относительно позиции спавнера.
  `OnDrawGizmosSelected` рисует границы области в окне Scene.

## Файлы

| Файл | Назначение |
|---|---|
| `Assets/Scripts/Spawner.cs` | спавнер: размещение объектов и вызов `WriteLog` |
| `Assets/Scripts/SpawnedObject.cs` | скрипт на префабе с методом `WriteLog(int i)` |
| `Assets/Prefabs/Cube.prefab` | префаб куба со скриптом `SpawnedObject` |
| `Assets/Scenes/SampleScene.unity` | сцена со спавнером |

## Как запустить

1. Открыть проект в Unity 6.6 (6000.6.5f1).
2. Открыть сцену `Assets/Scenes/SampleScene.unity`.
3. Нажать Play. Кубы появятся вокруг спавнера, в Console будет `Number` строк
   вида `Cube(Clone): i = 0`.

Параметры объекта `Spawner` на сцене настраиваются в инспекторе:
`Prefab` — что спавнить, `Number` — сколько, `Area Size` — размер области по осям.
