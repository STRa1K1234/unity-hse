# Семинар lvl.02 — вращающаяся фигура

Домашнее задание: фигура из родительского объекта и детей, вращения через иерархию
и один переиспользуемый скрипт, движение фигуры и облёт камеры.

## Что сделано

- **на 6** — в центре `Figure` с колонной `Body`, вокруг пять кубов.
  Все кубы вместе вращаются по орбите вокруг родителя относительно его оси Y.
- **на 8** — фигура двигается на WASD, камера облетает её стрелками,
  всегда смотрит на фигуру и перемещается вместе с ней.
- **на 10** — каждый куб дополнительно вращается вокруг своей оси X.

Отдельное требование «не считать вращения вручную» выполнено: в коде нет ни углов,
ни тригонометрии. Орбита получается из иерархии — кубы вложены в объект `Orbit`,
который вращается вокруг своей оси Y, и едут вместе с ним.

Все вращения делает **один скрипт** `Rotator`, он используется шесть раз:
один раз на `Orbit` (ось Y, 30 град/с) и по разу на каждом кубе (ось X, 120 град/с).
Отличаются только значения в инспекторе.

## Иерархия сцены

```
Figure                      FigureMover — движение на WASD
├── Body                    Cube, Scale (1, 3, 1) — колонна в центре
├── Orbit                   Rotator: Axis (0,1,0), Speed 30
│   ├── Arm (1)             Rotation Y = 0
│   │   └── Satellite       Cube, Position (0,0,3), Rotator: Axis (1,0,0), Speed 120
│   ├── Arm (2)             Rotation Y = 72    └── Satellite
│   ├── Arm (3)             Rotation Y = 144   └── Satellite
│   ├── Arm (4)             Rotation Y = 216   └── Satellite
│   └── Arm (5)             Rotation Y = 288   └── Satellite
└── CameraPivot             CameraRig — облёт стрелками и взгляд на фигуру
    └── Main Camera         Position (0, 2, -8)
```

Промежуточные объекты `Arm` расставляют кубы по окружности поворотом, а не подбором
координат: куб внутри всегда смещён на 3 по локальной оси Z, а по кругу его ставит
`Rotation Y` держателя. Поэтому у всех кубов одинаково ориентированы локальные оси
и собственное вращение выглядит одинаково.

Камера не следует за фигурой кодом: `CameraPivot` — дочерний объект `Figure`,
поэтому перемещается вместе с ним автоматически.

## Файлы

| Файл | Где висит | Назначение |
|---|---|---|
| `Assets/Scripts/Rotator.cs` | `Orbit` и каждый `Satellite` | единственный скрипт вращения |
| `Assets/Scripts/FigureMover.cs` | `Figure` | движение фигуры на WASD |
| `Assets/Scripts/CameraRig.cs` | `CameraPivot` | облёт камеры стрелками, взгляд на фигуру |

## Управление

| Клавиши | Действие |
|---|---|
| W A S D | двигать фигуру |
| стрелки влево/вправо | облёт камеры вокруг фигуры |
| стрелки вверх/вниз | поднять или опустить камеру |

## Как запустить

1. Открыть проект в Unity 6.6 (6000.6.5f1).
2. Открыть сцену `Assets/Scenes/SampleScene.unity`.
3. Нажать Play.

Ввод читается через Input System (`Keyboard.current`), так как в проекте
`Active Input Handling` стоит в режим Input System Package.
